# Multi-Agent Research Assistant - User Features

## Overview

A powerful AI-powered research assistant that combines multiple specialized agents to conduct comprehensive research, analyze documents, and generate insights.

## 🚀 Core Features

### Document Processing & Upload

**File Upload & Processing**
- **Drag & Drop Interface**: Drop files directly onto the upload area
- **Multiple File Support**: Upload multiple documents simultaneously
- **Supported Formats**: Text files, PDFs, Markdown, and other document types
- **Automatic Processing**: Files are automatically processed and made available to research agents
- **Context Preservation**: Uploaded documents remain accessible throughout the research session

**Usage**:
1. Drag files from your computer onto the file upload area
2. Files are automatically processed and integrated into your research
3. Reference uploaded content in your research queries
4. Documents persist across the entire research session

### Research Workflow

**Multi-Agent Research Process**
- **Search Agent**: Conducts web and local literature searches
- **Learnings Agent**: Analyzes and synthesizes research findings into stylized facts
- **Opportunity Analysis Agent**: Identifies research gaps and opportunities
- **Proposer Agent**: Generates research proposals and directions
- **Novelty Checker Agent**: Assesses proposal uniqueness and validity
- **Aggregator Agent**: Creates comprehensive final reports

**Real-Time Streaming**
- **Live Updates**: See agent responses as they're generated
- **Streaming Content**: Watch reports build in real-time
- **Progress Tracking**: Visual status indicators for each agent
- **Immediate Feedback**: No waiting for complete responses

### Session Management

**Persistent Sessions**
- **Auto-Save**: Research progress automatically saved
- **Session Recovery**: Resume where you left off after browser refresh
- **Session Sharing**: Generate shareable links to research sessions
- **Session Restore**: Auto-prompt to restore previous sessions

**Usage**:
- Sessions save automatically when research completes
- Use "Copy Link" button to share your research
- Paste shared URLs to restore exact session state
- Previous sessions auto-offer restoration on page load

### Selective Workflow Control

**Research Restart Options**
- **Restart from Search**: Keep existing research, add new search results
- **Restart from Proposal**: Keep search + analysis, regenerate proposals
- **Complete Restart**: Start fresh with new topic

**Usage**:
1. Provide feedback in the feedback panel
2. Choose restart type (Continue/Search Restart/Proposal Restart)
3. Workflow resumes from selected point while preserving relevant data

### Agent Output Navigation

**Iteration History**
- **Multiple Iterations**: View outputs from different research runs
- **Side-by-Side Comparison**: Compare different approaches and results
- **Historical Analysis**: Track how your research evolved
- **Agent-Specific Navigation**: Navigate iterations per agent

**Usage**:
- Click iteration buttons in each agent card
- Switch between different versions of agent outputs
- Compare results from different research iterations

### Customization & Templates

**Prompt Editing**
- **Agent-Specific Prompts**: Customize each agent's behavior
- **Real-Time Editing**: Edit prompts and see immediate effects
- **Template System**: Save and reuse research configurations
- **Default Templates**: Pre-configured setups for common research types

**Usage**:
- Click "Edit Prompt" on any agent card
- Modify agent instructions in the modal
- Save custom templates for future use
- Apply templates to new research sessions

### Export & Reporting

**Multiple Export Formats**
- **Markdown Export**: Complete research reports in Markdown
- **JSON Export**: Structured data for further analysis
- **Comprehensive Reports**: Include all agent outputs and metadata
- **Session Snapshots**: Export complete session state

**Usage**:
- Use "Export Run" for Markdown reports
- Use "Export JSON" for data analysis
- Reports include all agent outputs, prompts, and metadata

### Advanced Research Capabilities

**Tool Integration**
- **Web Search**: Automatic web research and content gathering
- **Local Search**: Search through uploaded documents and knowledge base
- **API Integration**: Connect to external research databases
- **Fallback Handling**: Graceful degradation when tools are unavailable

**Intelligent Analysis**
- **Gap Detection**: Automatically identify research gaps and opportunities
- **Novelty Assessment**: Evaluate proposal uniqueness against existing work
- **Synthesized Insights**: Generate stylized facts from complex research
- **Comprehensive Reporting**: Create executive summaries and detailed reports

## 🚀 Getting Started

5. **Review Results**: Examine outputs and provide feedback
6. **Iterate**: Restart and refine as needed
7. **Export**: Generate final reports and share findings
